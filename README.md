# Agent Local – iPhone PWA

Offline-first prototyp inspirerad av jaredrhod/fullstack-agent. Ingen språkmodell ingår ännu. Lokal chattlogg, minneskommandon, export, talsyntes där tillgänglig och animerat gränssnitt.

## iPhone-installation
Publicera repositoryt via GitHub Pages (Settings → Pages → Deploy from a branch → main / root). Öppna HTTPS-adressen i Safari, välj Dela → Lägg till på hemskärmen. Öppna appen online en gång och testa sedan offline.

## Begränsningar
Ingen fri AI-chatt, handstyrning eller lokal taligenkänning ännu. Safari kan rensa webbplatslagring: exportera minnen som backup. Ingen backend används.
